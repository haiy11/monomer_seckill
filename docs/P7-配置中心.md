# P7 配置中心 + 动态刷新（Nacos Config）实操指南

## 0. 前置条件

- 中间件就绪：MySQL(`localhost:3307`)、Redis(`localhost:6379`)、Nacos(`localhost:8848`)。
- JDK 21 + Maven 3.9.10（见 `seckill-build-run` skill）。

## 1. 发布配置到 Nacos

配置内容已整理在 `docs/P7-nacos-config/` 目录（13 个 dataId）。

在普通 PowerShell 中执行：

```powershell
cd E:\items\natherItems\monomer_seckill\docs\P7-nacos-config
.\publish-configs.ps1
```

发布成功后，打开 Nacos 控制台 `http://localhost:8848/nacos` →「配置管理 → 配置列表」，
应能看到 `seckill-common.yml`、`seckill-service.yml`、`seckill-service-dev.yml` 等 13 条配置。

> 若不想用脚本，也可在控制台手动新建配置：dataId 与文件同名，group 用 `DEFAULT_GROUP`，
> 格式选 YAML，内容粘贴对应文件。

## 2. 启动服务

启动顺序与 P6 相同：**先 goods-order-service（建表 + 种子数据），再 seckill-service、user-service，最后 gateway-service**。

```powershell
$env:JAVA_HOME = 'E:\app\config\java21'
$env:Path = 'E:\app\config\java21\bin;E:\app\config\Maven\Maven\apache-maven-3.9.10\bin;' + $env:Path

cd E:\items\natherItems\monomer_seckill\monomer_seckill_backend\monomer_seckill_backend_cloud
mvn -DskipTests clean package

# 分别启动（每个开一个终端，网关最后）
cd goods-order-service ; mvn spring-boot:run
cd seckill-service     ; mvn spring-boot:run
cd user-service        ; mvn spring-boot:run
cd gateway-service     ; mvn spring-boot:run
```

启动日志应出现：
- `[Sentinel 秒杀] 已加载熔断规则：...`
- `[Sentinel 网关] 已加载网关流控规则：seckill_api QPS=100.0`

说明规则阈值已从 Nacos 读取。

## 3. 验证一：动态刷新限流阈值（不重启）

1. 打开 Nacos 控制台，编辑 `gateway-service.yml`，把 `sentinel.gateway.seckill-qps` 从 `100` 改成 `5`，发布。
2. 观察 gateway-service 日志，几秒内出现：
   ```
   [Sentinel 网关] 检测到 Nacos 配置刷新，重载网关流控规则
   [Sentinel 网关] 已加载网关流控规则：seckill_api QPS=5.0
   ```
3. 用任意压测工具以 >5 QPS 持续打 `/api/seckill/**`（需带有效 JWT），即可看到 HTTP 429 限流响应，
   证明阈值已在不重启的情况下生效。

同理可改 `seckill-service.yml` 的 `sentinel.seckill.*`（熔断 RT/比例、热点限流）验证服务级规则刷新。

## 4. 验证二：JWT 密钥动态刷新

1. 用户正常登录拿到 token，正常访问受保护接口。
2. 修改 `seckill-common.yml` 的 `jwt.secret`（保持 ≥32 字节）并发布。
3. 再次用**旧 token** 访问，返回 401；重新登录拿到新 token 后可正常访问。
   （密钥轮换后旧 token 全部失效是预期行为）

## 5. 验证三：多环境切换

```powershell
# 默认 dev：加载 xxx.yml + xxx-dev.yml（debug 日志）
cd seckill-service ; mvn spring-boot:run

# 切 prod：加载 xxx.yml + xxx-prod.yml（info 日志 + 收紧的限流阈值）
cd seckill-service ; mvn spring-boot:run -Dspring-boot.run.arguments=--spring.profiles.active=prod
```

对比日志级别与 Sentinel 阈值即可看到差异。

## 6. 常见问题

| 现象 | 排查 |
|------|------|
| 启动报 `nacos ... config` 连接失败 | Nacos 未启动或 `server-addr` 不对 |
| 配置没加载，用了默认值 | dataId/group 是否与 `spring.config.import` 一致 |
| 改了配置不生效 | 对应 Bean 是否加 `@RefreshScope`；是否需重载第三方规则（如 Sentinel） |
| 中文注释乱码 | 发布时确保 UTF-8（脚本已用 `EscapeDataString` 处理） |
